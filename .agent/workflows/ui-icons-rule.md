# Правила використання візуальних символів в UI

Уникайте використання UTF-символів (емодзі, спеціальних знаків) безпосередньо у тексті кнопок, меню та міток, оскільки вони часто відображаються як "порожні прямокутники" через обмеження системних шрифтів користувача.

### 1. Використовуйте стандартні іконки Qt (QStyle)
Замість текстових символів використовуйте вбудовані іконки, які гарантовано працюють на будь-якій ОС.

```python
# Погано:
action = QAction("🔗 Об'єднати", self)

# Добре:
action = QAction("Об'єднати", self)
action.setIcon(self.style().standardIcon(QStyle.SP_DialogYesButton))
```

### 2. Замініть поширені символи на текст або іконки
| Символ | Заміна (Qt Standard Icon) |
| :--- | :--- |
| 🔗 / ⛓️ | `QStyle.SP_DialogYesButton` або `SP_FileDialogContentsView` |
| ✂️ / 🗑️ | `QStyle.SP_TrashIcon` або `SP_DialogDiscardButton` |
| 🔨 / 🔧 | `QStyle.SP_DialogResetButton` або `SP_TitleBarMenuButton` |
| 📁 / 📂 | `QStyle.SP_DirIcon` або `SP_FileDialogNewFolder` |
| 🔄 / 🔁 | `QStyle.SP_BrowserReload` |
| 🔼 / 🔽 | `QStyle.SP_ArrowUp` / `QStyle.SP_ArrowDown` |

### 3. Перевірка перед релізом
- Завжди перевіряйте вигляд контекстних меню (`QMenu`) та списків (`QListWidget`).
- Якщо емодзі критично необхідні, завантажуйте їх як `.png` або `.svg` файли ресурсів замість використання текстових кодів.
- Перевіряйте інтерфейс на різних ОС, якщо програма кросплатформна.
