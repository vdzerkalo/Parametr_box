# Генератор Коробок (Autonomous Box Generator)

Параметричний генератор коробок для 3D-друку (FDM) з пазловими стиками (зубці: шип/паз) між
сусідніми деталями. GUI на **PySide6**, геометрія — власний mesh-рушій на
**numpy + mapbox_earcut + shapely** (без CAD-ядра). Експорт у **STL**.

📖 **Повна документація:** [`docs/`](docs/README.md) — гайди користувача, архітектура,
розробка, [журнал змін](docs/CHANGELOG.md).

## Можливості

- Параметрична коробка: довжина/ширина/висота, товщина стінок, зубці на кожній грані
  (шип / паз / пряма), зазор, скруглення, кришка вазового режиму.
- Режим **Збирання**: розкладка коробок у 2D-пазлі, прилипання (snap), копіювання на сторону,
  поділ (split), об'єднання сусідів у суцільну деталь (merge → compound).
- **Конструктор сітки** (новий): задаєш зовнішні розміри ящика → авто-заповнення повною сіткою
  ячейок зі спільними стінками (PARTITIONED); редагування кожної ячейки з підлаштуванням решти
  (drawer-divider, зовнішній розмір фіксований); опційне дно; авто-сегментація на друковані
  модулі під розмір столу з безклейовими dovetail-швами. Див. нижче.
- Бібліотека пресетів/закладок, пакетний експорт у STL (з опцією об'єднання та ZIP).
- 3D-перегляд (pyqtgraph OpenGL), темна тема, лінійка, підписи розмірів, undo/redo.

## Вимоги

- **Python 3.11+** (працює і на 3.12 / 3.13 після видалення cadquery).
- Залежності — у [`requirements.txt`](requirements.txt).

## Встановлення та запуск

### Windows

Найпростіше — лаунчер (потребує [`uv`](https://docs.astral.sh/uv/) або наявний Python):

```bat
run_box_generator.bat
```

Або вручну:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Через `uv` (сам підтягне потрібний Python):

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

### Linux

```bash
./run_box_generator.sh
```

(скрипт створює ізольоване середовище через micromamba та запускає застосунок)

## Збірка портативного EXE (Windows)

```powershell
uv pip install --python .venv\Scripts\python.exe pyinstaller
.\.venv\Scripts\pyinstaller.exe box_generator.spec
# результат: dist\BoxGenerator_Portable\
```

CI робить це автоматично — див. [`.github/workflows/build_windows.yml`](.github/workflows/build_windows.yml).

## Конструктор сітки-органайзера

У режимі **Збирання** розгорніть панель **«Конструктор сітки»**:

1. Задайте зовнішні **L × W × H**, кількість **стовпців (X)** та **рядів (Y)**, **товщину стінки**.
2. (Опційно) увімкніть **Дно** і задайте його товщину.
3. **Сегментація:** `Моноліт` (один шматок) · `Розрізати по столу` (авто-розбиття на найменше
   число модулів під розмір столу) · `Ручне групування` (свої розрізи, напр. «2,4» по X) ·
   `Кожна ячейка окремо`.
4. **Тип шва:** `Dovetail` (безклейовий вертикальний слайд-замок між модулями) або `Без шва`.

Сітка **оновлюється в реальному часі** — окремої кнопки немає: щойно розкриваєте панель,
з'являється сітка, а будь-яка зміна параметра одразу її перебудовує.

**Редагування ячейки** (drawer-divider, зовнішній габарит фіксований):

- **Перетягування стінки** — у вкладці «Пазл (2D)» наведіть курсор на внутрішню стінку між
  комірками (курсор зміниться на ↔ / ↕) і **тягніть** — дві сусідні комірки міняють розмір
  у реальному часі.
- **Подвійний клік по комірці** → редагування **прямо в комірці**: два поля `Ширина × Глибина`
  з фіксованим `×` (Tab/Space — перемкнути поле, Enter — застосувати). Комірка **автоматично
  фіксується** (🔒) — її розмір більше не змінюється, коли правите інші. Праворуч авто-розгортається
  блок **«Редактор комірки»** з полями Ш/Г, перемикачами 🔒 та кнопкою «Розблокувати все».
- **Правий клік по сітці** → контекстне меню: ➕ розрізати тут (новий стовпець/ряд),
  🗑 видалити стовпець/ряд, 🔓 зняти фіксацію комірки.
- **Ctrl + клік** по кількох комірках → виділення (підсвічуються блакитним); заданий розмір
  застосується одразу до **всіх** вибраних стовпців/рядів.
- Якщо фіксацій забагато і немає що підлаштувати — знизу зʼявиться **підказка** (розблокуйте
  сусідні або змініть зовнішній розмір).

Зафіксовані комірки у 2D показані **золотим із 🔒**. Усе з клампом до мінімального розміру;
решта (вільних) комірок підлаштовується автоматично, зовнішній габарит фіксований.
У 2D всередині кожної комірки показано її розмір **Д×Ш×В** (мм).

**Перегляд** (кнопки над сценою): **2D** (лише редактор) · **2D+3D** (спліт — правки у 2D
одразу видно у 3D праворуч) · **3D** (лише модель). Наведення на будь-який контрол показує
підказку-тултіп. Параметри застосовуються в реальному часі (без кнопок).

Геометрія: кожен друкований модуль — це суцільна оболонка зі спільними внутрішніми перегородками
(`polygon-with-holes`), друкується **стоячи** (шви та стінки в міцній XY-площині), модулі
з'єднуються dovetail-швами без клею. Логіка — у `grid_engine.py`
(тести: `test_grid_constructor.py`).

## Структура

| Файл | Призначення |
|---|---|
| `main.py` / `app.py` | Точка входу, головне вікно (мікс-іни) |
| `mesh_engine.py` | Mesh-рушій: екструзія 2D-контуру (+ отвори), offset, запис STL |
| `grid_engine.py` | Рушій сітки-органайзера: модулі, dovetail-шви, дно |
| `mixins/grid_constructor.py` | UI-панель та логіка конструктора сітки |
| `mixins/geometry.py` | Генерація геометрії коробки та збірки, зубці, кришка |
| `mixins/assembly.py` | 2D-збирання: snap, split, merge, flatten |
| `mixins/ui_setup.py` | Побудова інтерфейсу |
| `mixins/bookmarks.py` | Бібліотека пресетів, пакетний експорт |
| `puzzle_item.py` | Елементи 2D-пазла (коробка / compound) |

## Примітки щодо Windows

- Експорт STEP вимкнено — рушій працює лише з mesh-даними (STL/OBJ).
- Налаштування зберігаються у реєстрі (`HKCU\Software\KasNew\BoxGenerator`),
  пресети — у теці `presets/` поруч із застосунком.
