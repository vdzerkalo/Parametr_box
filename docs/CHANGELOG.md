# Журнал змін

## Конструктор сітки-органайзера (нове)

Велика нова підсистема — параметричний конструктор органайзерів. Деталі:
[гайд](user-guide/grid-constructor.md), [рушій](architecture/grid-engine.md).

**Геометрія / модель**
- `grid_engine.py` — рушій сітки: solve-from-outer, PARTITIONED-стінки як polygon-with-holes,
  опційне дно, безклейові dovetail-шви між модулями, сегментація (моноліт / по столу / ручна /
  по-ячейково).
- `mesh_engine.extrude_polygon_with_holes` — екструзія контуру з отворами (реальні перегородки).
- Lock-aware перерозподіл: `redistribute_locked`, `rescale_free`, `redistribute_locked_multi`;
  `add_split`, `remove_line`.
- Новий тип елемента `placed_items` — `{"type": "grid", "grid_config": {...}}`.

**Інтерфейс / взаємодія**
- Окрема панель **«Конструктор сітки»** з оновленням у **реальному часі** (без кнопки «Згенерувати»).
- **3 режими перегляду**: 2D / 2D+3D (спліт) / 3D через `QSplitter`; live-3D під час перетягування.
- 2D-елемент `PuzzleGridItem`: підписи **Д×Ш×В** у кожній ячейці (повертаються/скорочуються
  у вузьких), пунктирні лінії швів, підсвічування вибору.
- Редагування ячейки: перетягування стінки, **інлайн-редактор** `Ш × Г` (фіксований `×`,
  Tab/Space, Enter), окремий блок **«Редактор комірки»** (авто-розгортання на 2-клік).
- **Фіксація (lock)**: авто-фіксація на правці; золоті ячейки з 🔒; підказка, коли немає
  вільних комірок підлаштувати.
- **Правий клік** → додати/видалити розріз, зняти фіксацію.
- **Ctrl + клік** → мультивибір ячейок і спільний розмір.
- Тултіпи на всіх контролах; per-cell тултіпи у 2D.
- Продуктивність: throttle live-3D (130 мс), debounce параметрів (350 мс), оновлення 2D
  на місці під час drag; райдужна анімація більше не перемальовує сітку та неактивне 2D.

**Тести**: `test_grid_constructor.py` (рушій + інтеграція + locks + split/multi).

## Windows-адаптація та інфраструктура

- **Прибрано рудиментний `cadquery`** (STEP-експорт був вимкнений, пакетний — зламаний на
  MeshData): пакетний експорт переведено на спільний `mesh_engine.write_ascii_stl`. Це
  розблокувало **Python 3.12/3.13** і прибрало ~87 МБ залежностей (OCP).
- `requirements.txt`: прибрано `cadquery`, розпінено numpy (`numpy>=1.26`).
- **`run_box_generator.bat`** — Windows-лаунчер (ASCII-only), **самовідновлюваний**: створює/
  ремонтує `.venv` із системного Python (`py -3.12/3.13/3.11`), показує помилки, не зникає.
- **`main.py`** — шим: `python main.py` будь-яким інтерпретатором авто-перемикається на `.venv`.
- `box_generator.spec` (+ знято `*.spec` з `.gitignore`) — для CI-збірки портативного EXE.
- Тека-зразок `7*7*10/` із недопустимим `*` (ламала `git clone` на Windows) — позначена до
  видалення з індексу.
- Додано `README.md`.
