# Mesh-рушій (`mesh_engine.py`)

Низькорівнева геометрія: перетворення 2D-контурів у 3D-меші та запис STL.
Без Qt і без CAD — лише `numpy`, `mapbox_earcut`, `shapely`.

## `MeshData`

Контейнер меша.

```python
MeshData(verts, faces)        # verts: (N,3) float32; faces: (M,3) int32
.translate(dx, dy, dz)
.rotate_z(angle_deg)
MeshData.combine([meshes])    # обʼєднати з коректним зсувом індексів
```

## `extrude_polygon(pts_2d, height) → MeshData`

Екструдує **простий** 2D-контур (без отворів) у 3D:
- нижня грань (тріангуляція earcut, нормаль вниз),
- верхня грань (та сама тріангуляція, +height),
- бічні стінки (квади → 2 трикутники на ребро).

Використовується для коробок (контур із зубцями).

## `extrude_polygon_with_holes(exterior, holes, height, z0=0.0) → MeshData`

Екструзія контуру **з отворами** (внутрішніми кільцями). Earcut отримує масив `rings`
із межами кілець; бічні стінки будуються окремо для зовнішнього кільця та кожного отвору.

- `exterior` — зовнішнє кільце (CCW), `holes` — список кілець-отворів (CW).
- `z0` — нижня площина.

Це основа **PARTITIONED-стінок** конструктора сітки (зовнішня оболонка мінус порожнини комірок
= полігон зі стінками). Орієнтація кілець нормалізується за знаком площі.

## `offset_polygon_2d(pts_2d, offset) → list[pt]`

Внутрішній/зовнішній зсув контуру через `shapely.buffer` (mitre join). При розпаді на
`MultiPolygon` повертає найбільший. Використовується для внутрішньої кришки.

## `write_ascii_stl(path, verts, faces, name) → None`

Записує ASCII STL із масивів вершин/граней (рахує нормалі). Спільний хелпер для одиночного
та пакетного експорту (рушій не використовує cadquery).

## Чому без CAD

Рушій екструдує **суцільний призм** з одного контуру — немає товщини стінок, дна чи порожнини
як у соліда. Стінки/порожнину формує **слайсер** (периметри + 0% інфіл). Тому «спільні стінки»
у конструкторі сітки моделюються геометрично: окремі контури комірок або зовнішня оболонка
мінус порожнини (через `extrude_polygon_with_holes`). Див. [Рушій сітки](grid-engine.md).
