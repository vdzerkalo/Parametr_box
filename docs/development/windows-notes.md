# Нотатки по Windows

## Стан адаптації

Застосунок повністю працює на Windows. Логіка кросплатформена (шляхи через `os.path.join`,
UTF-8, `QSettings` через реєстр). Нижче — Windows-специфічні моменти й виправлення.

## Виправлено

### Лаунчер `run_box_generator.bat`
- **Тільки ASCII** всередині `.bat`. Причина: `cmd.exe` читає `.bat` у системному OEM-кодуванні;
  кирилиця в UTF-8 ламає кожен рядок (вікно блимає й закривається).
- **Самовідновлюваний**: перевіряє `.venv`, і якщо відсутнє/зламане — перестворює із
  **системного Python** (`py -3.12 → 3.13 → 3.11 → 3 → python`). Системна база стабільна
  (на відміну від uv-керованого Python, шлях якого може «поїхати»).
- На помилці вікно **не зникає** (`pause`) і показує текст.

### Шим у `main.py`
`python main.py` будь-яким інтерпретатором: якщо бракує залежностей — авто-`os.execv` у
`.venv\Scripts\python.exe`. Інакше — зрозуміла підказка замість сирого `ImportError`.

### Прибрано cadquery
- STEP-експорт був вимкнений; пакетний експорт у bookmarks падав (передавав `MeshData` у
  `cq.Compound`). Переведено на `mesh_engine.write_ascii_stl`.
- Це **розблокувало Python 3.12/3.13** (cadquery-ocp мав wheels лише для ≤3.11) і прибрало
  ~87 МБ (OCP). `numpy` розпінено.

### Тека `7*7*10/`
Містила `*` у назві — **недопустимий символ у Windows**, через що `git clone` падав
(checkout аварійно зупинявся). Це невикористовувані .step-зразки; позначені до видалення
з індексу. Для повного фіксу — закомітити й запушити.

### CI-збірка
`box_generator.spec` додано до репозиторію (раніше `*.spec` був у `.gitignore`, тож
`build_windows.yml` падав на `pyinstaller box_generator.spec`).

## Типові пастки запуску

| Симптом | Причина | Рішення |
|---|---|---|
| `ModuleNotFoundError: PySide6` | запуск системним Python без залежностей | шим у `main.py` авто-перемикає на `.venv`; або `run_box_generator.bat` |
| cmd блимає й закривається | стара кирилична `.bat` / помилка venv | оновлений ASCII-лаунчер показує помилку й не зникає |
| `No Python at '...uv\python...'` | venv на uv-керованому Python, що зник | лаунчер перестворює venv із системного Python |

## Версії Python

- Рекомендовано **3.12** (зрілі wheels).
- Працює 3.11–3.13. На 3.13 ставиться numpy 2.x (сумісно після видалення cadquery).
