# Режим «Збирання» — 2D-пазл і бібліотека

Режим для розкладки кількох коробок як пазлів та обʼєднання їх у суцільні деталі.
Тут само живе [Конструктор сітки](grid-constructor.md).

## Сцена

- **Пазл (2D)** / **Камера (3D)** / **2D+3D** — перемикач перегляду над сценою.
- **Нерозміщені обʼєкти** / **Обʼєкти в збірці** — списки.
- **Панель інструментів** — коробки з обраної папки пресетів; «Додати на стіл».

## Дії над коробками

| Дія | Як |
|---|---|
| Перемістити | Перетягнути в 2D |
| Поворот 90° | ПКМ / кнопки 0°/90°/180°/270° |
| Прилипання (snap) | Авто при відпусканні поряд із сумісною стороною |
| Копіювати на сторону | Контекстне меню — створює сусіда із синхронізованими зубцями |
| Поділ (split) | Розрізати коробку на дві з розподілом зубців |
| Обʼєднати (merge) | Дві сусідні → один `compound` (суцільна деталь) |
| Flatten | Зробити вільні (зовнішні) краї рівними |
| Уникати зіткнень | Чекбокс «Колізії» — не дає накладати деталі |

## Обʼєднання в суцільну деталь

При `merge` сусідні коробки стають одним `compound`: внутрішні зубці ховаються
(`is_internal`), мікрощілини від зазору закриваються вузькими «містками» (0.75 мм),
профіль обʼєднується через `shapely.unary_union` і екструдується як одна деталь.
Структуру `parts[]` збережено, тож деталь можна розʼєднати назад.

## Бібліотека пресетів

- Дерево папок/закладок, пошук за назвою.
- Зберегти/Замінити пресет, кольорові папки.
- **Пакетний експорт** папки у STL (з опціями обʼєднання та ZIP).
- Імпорт/Експорт бібліотеки у ZIP.

## Збереження

- **Зберегти/Завантажити збірку** — `.json` зі списком `placed_items`
  (див. [Модель даних](../architecture/data-model.md)).
- Поточний стан авто-зберігається в реєстр і відновлюється при старті.
