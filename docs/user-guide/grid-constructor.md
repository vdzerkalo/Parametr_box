# Конструктор сітки (органайзер)

Параметричний конструктор, що за **зовнішніми розмірами ящика** автоматично заповнює його
**сіткою ячейок зі спільними стінками** (PARTITIONED) і дозволяє редагувати кожну ячейку.
Призначений для друку органайзерів окремими модулями зі зʼєднанням **без клею** (dovetail).

> Розташування: режим **Збирання** → панель **«Конструктор сітки»** на бічній панелі.

## 1. Створення сітки

Розгорніть панель «Конструктор сітки» — сітка зʼявиться автоматично. Параметри застосовуються
**в реальному часі** (кнопки «Згенерувати» немає):

| Поле | Опис |
|---|---|
| Зовн. довжина L / ширина W / висота H | Зовнішні габарити ящика (мм) |
| Стовпців (X) / Рядів (Y) | Кількість ячейок |
| Товщина стінки | Усі стінки (мм); кратна 0.4 (сопло) → міцніший друк |
| Дно + товщина | Опційне дно у відсіках |
| Сегментація | Як ділити на друковані шматки (див. нижче) |
| Тип шва | `Dovetail` (безклейовий) або `Без шва` |

Внутрішній розмір ячейок розраховується автоматично: `inner_total = L − 2·wall − (nx−1)·wall`,
рівномірно між стовпцями. Зовнішній габарит **завжди фіксований**.

## 2. Сегментація (поділ на друковані модулі)

Бажано мінімізувати кількість швів без втрати міцності, тому за замовчуванням сітка —
**один моноліт** зі спільними стінками. Розріз зʼявляється лише за потреби:

- **Моноліт** — один шматок (нуль розʼємних швів).
- **Розрізати по столу** — авто-розбиття на найменше число шматків під `bed_x × bed_y`.
- **Ручне групування** — свої лінії розрізу (поля «Ручні розрізи», напр. `2,4`).
- **Кожна ячейка окремо** — кожен відсік як окремий модуль.

Лінії розрізу між модулями показані **помаранчевим пунктиром** у 2D.

## 3. Перегляд: 2D / 2D+3D / 3D

Кнопки над сценою:
- **2D** — лише редактор-пазл.
- **2D+3D** — спліт: редактор ліворуч, 3D-модель праворуч; правки видно у 3D **в реальному часі**.
- **3D** — лише модель (вільне обертання).

## 4. Редагування ячейок

Зовнішній габарит фіксований (модель «drawer-divider»): зміна однієї ячейки перерозподіляє
**вільні** (не зафіксовані) ячейки тієї ж осі.

### Перетягування стінки
У 2D наведіть курсор на внутрішню стінку (курсор ↔ / ↕) і тягніть — дві сусідні ячейки
міняють розмір наживо.

### Подвійний клік — інлайн-редактор
Зʼявляються два поля `Ширина × Глибина` з фіксованим `×`:
- **Tab** або **Space** — перемкнути між полем №1 і №2;
- **Enter** — застосувати; **Esc** — скасувати.

Після зміни ячейка **автоматично фіксується** (🔒) — її розмір більше не змінюється, коли
правите інші. Праворуч авто-розгортається блок **«Редактор комірки»** з полями Ш/Г,
перемикачами 🔒 та кнопкою «Розблокувати все».

### Фіксація (lock)
- Зафіксовані ячейки у 2D показані **золотим із 🔒**.
- Якщо змінити ячейку неможливо (усі сусіди зафіксовані або вже на мінімумі) — знизу
  зʼявиться **підказка** (розблокуйте сусідні або змініть зовнішній розмір).

### Правий клік — розрізи
Контекстне меню:
- ➕ **Розрізати тут вертикально** (новий стовпець у точці кліку);
- ➕ **Розрізати тут горизонтально** (новий ряд);
- 🗑 Видалити стовпець / ряд (його розмір додається до сусіда);
- 🔓 Зняти фіксацію цієї комірки.

### Ctrl + клік — мультивибір
Виділіть кілька ячейок (підсвічуються блакитним) — заданий розмір застосується одразу
до **всіх** вибраних стовпців/рядів. Звичайний 2-клік поза вибором скидає його.

### Підписи розмірів
Усередині кожної ячейки показано **Д×Ш×В** (мм). У вузьких ячейках підпис **повертається
вертикально** або скорочується до `Д×Ш`.

## 5. Зʼєднання модулів і міцність

- У межах модуля — спільні стінки (нуль розʼємних швів).
- Між модулями — вертикальний **dovetail-замок** (друкуєте стоячи, зсуваєте по Z) без клею.
- Друк **стоячи** → і перегородки, і шви лежать у міцній XY-площині.

## 6. Експорт і збереження

- **Зберегти/Завантажити збірку** — у JSON (включно з `grid_config`).
- Експорт у **STL** (кнопка STL у режимі Генерація працює для поточної фігури; для збірки —
  через пакетний експорт бібліотеки).

## Обмеження v1

- Єдина висота для всієї сітки (різна висота відсіків — окремий етап).
- Перетягування стінки навмисне ігнорує lock (це пряма дія); lock захищає від *непрямих* змін.
