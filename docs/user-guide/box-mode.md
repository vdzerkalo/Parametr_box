# Режим «Генерація» — одна коробка

Параметрична генерація однієї коробки, що друкується у **вазовому режимі** (спіральний контур),
з пазловими стиками (зубцями) на гранях для зʼєднання із сусідніми коробками.

## Основні параметри

| Група | Поля |
|---|---|
| Розміри | Довжина, Ширина, Висота (мм) |
| Зубці (tabs) | Базова ширина, ширина кінчика, глибина, зазор (clearance), скруглення |
| Сторони | Top / Bottom / Left / Right — кожна: **шип** (male, 0), **паз** (female, 1) або **пряма** (2) + кількість зубців |
| Кришка | Вазова кришка з допуском і екструзією, авто-розміщення поряд із коробкою |
| Стіл | Розмір столу (bed_x, bed_y) для авто-розміщення коробки+кришки |

## Як працює геометрія

Коробка — це **2D-контур**, екструдований у 3D. На кожній грані за параметрами додаються
зубці (трапеції). Зубець: `mode 0` = шип (виступ назовні), `mode 1` = паз (вріз усередину,
розширений на `clearance` для люфту), `mode 2` = пряма стінка.

Контур будується одним обходом (CCW), за потреби скруглюється (`shapely.buffer`), потім
екструдується (`mesh_engine.extrude_polygon`). Деталі: [Mesh-рушій](../architecture/geometry-engine.md).

## Зʼєднання коробок

Сусідні коробки стикуються зубцями: шип однієї входить у паз іншої. Протилежні сторони
мають бути сумісні (один `male`, інший `female`, однакова кількість і довжина).

## Експорт

- **STL** — для 3D-друку (ASCII STL, `mesh_engine.write_ascii_stl`).
- **STEP** — вимкнено (новий mesh-рушій працює лише з даними для друку).

## Перегляд

- Темна тема, 3D-в’юпорт (pyqtgraph OpenGL), підписи осей/розмірів, лінійка, undo/redo.
