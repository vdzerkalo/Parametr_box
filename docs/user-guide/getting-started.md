# Початок роботи

## Системні вимоги

- **Windows** (основна платформа) або Linux.
- **Python 3.11–3.13** (після видалення cadquery працює на сучасних версіях).
- ~500 МБ на диску під залежності (PySide6, numpy, shapely тощо).

## Встановлення та запуск

### Windows — найпростіше

Двічі клацніть **`run_box_generator.bat`**. Лаунчер сам:
1. створить ізольоване середовище `.venv` із системного Python (`py -3.12/3.13/3.11`);
2. встановить залежності (одноразово, ~1–2 хв);
3. запустить застосунок.

Лаунчер **самовідновлюваний**: якщо `.venv` зламано чи відсутнє — він його перестворить.
Вікно cmd **не зникає** на помилці й показує її текст.

### Windows — вручну

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

`python main.py` будь-яким Python теж спрацює — `main.py` має шим, що авто-перемикається
на `.venv`, якщо в поточному інтерпретаторі бракує залежностей.

### Linux

```bash
./run_box_generator.sh
```

## Перший запуск

1. Застосунок відкривається в режимі **Генерація** (одна коробка).
2. Угорі бічної панелі — перемикач **Генерація / Збирання**.
3. Для конструктора органайзерів: **Збирання** → панель **«Конструктор сітки»**
   ([гайд](grid-constructor.md)).

## Де зберігаються дані

- Налаштування — у реєстрі Windows: `HKCU\Software\KasNew\BoxGenerator`.
- Пресети/закладки — у теці `presets/` поруч із застосунком.
- Збірки/сітки — у `.json` (Зберегти/Завантажити збірку).
